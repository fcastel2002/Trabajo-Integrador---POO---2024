Este proyecto es un cliente en C++ que utiliza bibliotecas externas como `PDCurses` y `XMLRPC++`. Se construye y gestiona mediante CMake y está diseñado para ejecutarse en Windows usando MinGW.

Para su compilacion y ejecucion:

1. Dirigirse a la carpeta "bins"
2. Abrir una terminal de comandos en dicha ruta
3. Ejecutar el comando "mingw32-make" 
4. Ejecutar la aplicacion desde la ventana de comandos

Si se desea probar la compilacion puede borrarse el .exe existente y volver a compilar uno nuevo

El archivo Makefile fue creado mediante CMakeLists.txt y la GUI de CMake.
